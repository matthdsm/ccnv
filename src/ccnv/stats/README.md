# `ccnv.stats`

## Overview

The `ccnv.stats` package provides pure, stateless numerical and machine learning kernels for `ccnv`: deterministic SVD/PCA with Gavish-Donoho Singular Value Hard Thresholding (SVHT) on variance-whitened residuals, Prototype Graph ($`M \le 2{,}048`$) reference modeling, Smyth Empirical Bayes biological overdispersion moderation (`squeeze_var`, `bio_dispersion`), `PoissonRegressor` covariate modeling, compiled Rust `ccnv._core.pelt_weighted_l2` PELT segmentation with modified BIC (mBIC) penalty, dyadic multi-scale BLUE Z-score aggregation, discrete integer copy-number Bayes factors ($`CN \in \lbrace 0, 1, 2, 3, 4+\rbrace`$), closed-form Poisson MSY `FFY`, forward $`R_X`$, 4D erfc ray-marginalized SCA, Student-$`t_4`$ IRLS active FF fusion, 24-band Fisher read weighting, and fragmentomic deconvolution and ensemble regression.

## Interface

- [`neighbors.py:LN2_SQ`](./neighbors.py), [`build_whitened_subspace_features`](./neighbors.py), [`fit_prototype_graph`](./neighbors.py), [`compute_loco_prototype_support`](./neighbors.py), [`evaluate_loco_prototype_baseline`](./neighbors.py), [`compute_kish_loco_inflation`](./neighbors.py), [`exact_poisson_log_variance`](./neighbors.py), [`exact_poisson_log2_jensen_bias`](./neighbors.py), [`calibrate_prototype_dispersion`](./neighbors.py), & [`squeeze_var`](./neighbors.py): Build MiniBatch K-Means Prototype Graph ($`M \le 2{,}048`$) in standardized signal subspace with $`k=4`$ soft inverse-distance weights, evaluate leave-one-contig-out (LOCO) prototype baselines and donor support, subtract exact Poisson shot-noise variance, and apply Smyth (2004) Empirical Bayes shrinkage to isolate depth-decomposed biological overdispersion (`bio_dispersion`).

- [`prenatal_math.py:compute_autosomal_density`](./prenatal_math.py) & [`fit_forward_ffx_model`](./prenatal_math.py): Chromosome-median ratio-of-sums autosomal read density estimation and forward-calibrated $`R_X`$ baseline regression across `XX` ($`f=0`$) and `XY` ($`f=\hat{f}_{\text{FFY}}`$) controls.

## Invariants

- [`pca.py:fit_whitened_pca`](./pca.py): Selects rank in $`[0, \min(P_{\max}, S - 2, U - 1)]`$ with deterministic singular-vector sign orientation.
- [`neighbors.py:evaluate_loco_prototype_baseline`](./neighbors.py) & [`compute_loco_prototype_support`](./neighbors.py): Enforce leave-one-contig-out (LOCO) donor exclusion so target bins never draw baseline support from bins on the same contig.
- [`segmentation.py:segment_contig`](./segmentation.py): Requires sorted non-overlapping intervals ($`\text{start}_{i+1} \ge \text{end}_i`$), positive finite penalty or sensitivity, and $`\text{jump} \ge 1`$.
- [`fragmentomics.py:compute_band_fisher_weights`](./fragmentomics.py): Enforces unit expectation under maternal density $`\hat{p}_M`$ within $`[0.25, 3.0]`$ using target fetal fraction $`f_0 = 0.08`$.
