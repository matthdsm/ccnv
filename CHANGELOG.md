## [1.0.0] - 2026-11-20

### Added

- **Four-Stage CLI & Python API (`extract`, `reference`, `ref-qc`, `predict`)**: Organism-agnostic whole-genome sequencing (WGS) copy-number analysis across any sequencing depth on 0-based half-open `[start, end)` genomic coordinates, supporting constitutional CNV detection (`--mode germline`) and cell-free DNA non-invasive prenatal screening (`--mode prenatal`) via the `ccnv` CLI and lazy Python entry points (`run_extract`, `run_reference`, `run_reference_qc`, `run_predict`).
- **Compiled Rust Genomic I/O Engine (`ccnv._core`)**: PyO3 `abi3` Rust extension wrapping `noodles` and `bigtools` for parallel indexed BAM/CRAM tile streaming (with automatic sequential fallback when alignment indexes are absent), mate-deduplicated dyad midpoint and `TLEN == 0` pair handling, single-pass FASTA GC and 200 bp GC quantile scanning, BigWig covariate aggregation, and multi-threaded BGZF compression with `.tbi`/`.csi` indexing.
- **Privacy-Safe Arrow/Parquet Storage (`2.0.0`) & Dynamic Rebinning**: Zstandard-compressed Apache Arrow/Parquet `.ccnv` schema storing coordinate-free per-bin read counts, cfDNA fragmentomic channels (`paired_count`, `frag_len_sum`, `short_frag_count`, `endpoint_count`, `frag_gc_sum`, and 24 variable-width `frag_bands`), sample-level insert-size histograms, and 5' 4-mer end-motif spectra without persisting internal filesystem paths or clinical sample identifiers, alongside branch-partitioned reference models and automatic in-memory rebinning across matching contig layouts.
- **Within-Sample Reference Normalization & Cohort Modeling**: Cohort samplesheet (`-s/--samplesheet`) and cohort-free FASTA (`--fasta`) reference building with 2D germline sex inference and sex-chromosome outlier quarantine, 1 Mb super-block DESeq2 depth scaling, zero-inclusive Poisson GC/mappability/fragmentomic bias normalization, Gavish-Donoho SVHT PCA denoising with `HuberRegressor` projection, off-contig `MiniBatchKMeans` Prototype Graph baselines, and Empirical Bayes biological overdispersion shrinkage.
- **Calibrated Segmentation & Copy-Number Calling**: Gap-aware euchromatic chromosome-arm splitting (`--max-blacklist-gap`), mBIC-calibrated `ruptures.Pelt` change-point segmentation, multi-scale dyadic BLUE segment Z-scores, and compound-Poisson adjusted discrete integer copy-number Bayes factor calling ($`CN \in \lbrace 0, 1, 2, 3, 4+\rbrace`$) resolving homozygous deletions ($`CN = 0`$) down to $`0.1\times`$ coverage as well as standard high-depth WGS.
- **Prenatal cfDNA Screening, Twin Stoichiometry & 5-State Segment Origin Classification**: Student-$`t_4`$ IRLS fusion (`active_ff`) across Empirical Bayes-calibrated Poisson MSY `FFY`, cross-validated 100 kb `FFA` logit-link ensemble, forward-calibrated `FFX`, and sizing-shift aligned `FF_size` deconvolution with compound-Poisson 24-band Fisher read weighting; 4D `erfc` ray-marginalized singleton SCA classification (`XX`, `XY`, `XO`, `XXX`, `XXY`, `XYY`, `DISCORDANT_MIXED`) paired with twin pregnancy stoichiometry (`FF`, `FM`, `MM`, `--twins`); male-fetus 5 kb `chrY` MSY normalization (`prenatal_ffy`); analytical limits of detection; and a 5-state coupled depth and Dirichlet-Multinomial segment origin model (`FETAL_CONSTITUTIONAL`, `PLACENTAL_MOSAIC`, `MATERNAL_UNINHERITED`, `MATERNAL_AND_FETAL_INHERITED`, `MATERNAL_MOSAIC`, `INDETERMINATE`).
- **Deliverables, Interactive Visualization & Reference/Sample Quality Control**: Single-pass bgzipped and indexed BED tracks, optional VCFv4.2 structural variant files (`--vcf`, `--bins-vcf`), self-contained Plotly WebGL HTML genome viewers (`_plot.html`) with M4 trace decimation and UCSC cytoband ideograms (bundled GRCh38 `cytoBand_hg38.gz` auto-matching or `--cytobands`), and structured QC JSON diagnostics (`<prefix>_qc.json`) including `ccnv ref-qc` usability verdicts (`PASS`, `WARN`, `FAIL`) and organism-agnostic unmasked signal-contig coverage checks.
- **Galaxy Tool Suite (`galaxy/`)**: IUC-compatible 4-tool Galaxy suite (`ccnv_extract`, `ccnv_reference`, `ccnv_ref_qc`, `ccnv_predict`, shared `macros.xml`, and `.shed.yml` for `suite_ccnv`) providing extensionless `.dat` symlink staging, index-aware thread fallback, automated cohort `samplesheet.json` creation, decompressed `bed` and `vcf_bgzip` output mappings, `pixi run bump-version` `@TOOL_VERSION@` synchronization, and contract tests.
- **Documentation, Packaging & CI/CD**: Zensical documentation site covering [Pipeline Architecture](docs/pipeline.md), [CLI Reference](docs/cli.md), [Visualization Overview](docs/visualization.md), [API Reference](docs/api.md) (with AST-verified module/signature tables and Mermaid call-graph DAGs), and [Mathematical Methodology](docs/methodology.md), Pixi maintenance tasks (`bump-version`, `bump-schema`), multi-platform Python `abi3` wheel builds (`linux/x86_64`, `linux/aarch64`, `macos/arm64`), and multi-architecture GHCR Docker images.
