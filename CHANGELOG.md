### Added

- **Four-Stage CLI & Python Pipeline**: Organism-agnostic whole-genome sequencing (WGS) copy-number workflow across any coverage via `ccnv extract`, `ccnv reference`, `ccnv ref-qc`, and `ccnv predict` (plus programmatic `ccnv` entry points), supporting constitutional CNV profiling (`--mode germline`) and cell-free DNA non-invasive prenatal screening (`--mode prenatal`) on 0-based half-open `[start, end)` coordinates.
- **Compiled Rust Genomic I/O Engine (`ccnv._core`)**: PyO3 `abi3` Rust extension wrapping `noodles` and `bigtools` for multi-threaded indexed BAM/CRAM tile streaming (and index-free single-threaded streaming), single-pass FASTA GC and 200 bp GC quantile scanning, BigWig mappability and GC aggregation, and multi-threaded BGZF compression with `.tbi`/`.csi` indexing.
- **Versioned Arrow/Parquet Storage & Dynamic Rebinning**: Zstandard-compressed Apache Arrow/Parquet `.ccnv` schema (`2.0.0`) storing coordinate-free per-bin read counts and cfDNA fragmentomic channels (`paired_count`, `frag_len_sum`, `short_frag_count`, `endpoint_count`, `frag_gc_sum`, and 24-band `frag_bands`), sample-level fragment size histograms and 5' 4-mer end-motif spectra, branch-partitioned reference models, and automatic in-memory rebinning across compatible genome builds.
- **Within-Sample Reference Normalization & Cohort Modeling**: Cohort samplesheet (`-s/--samplesheet`) and cohort-free FASTA (`--fasta`) reference construction with automated 2D germline sex inference and outlier quarantine, 1 Mb super-block DESeq2 depth scaling, zero-inclusive Poisson GC/mappability/fragmentomic bias correction, Gavish-Donoho SVHT PCA denoising with robust `HuberRegressor` projection, off-contig `MiniBatchKMeans` Prototype Graph baselines, and Smyth Empirical Bayes biological overdispersion shrinkage.
- **Calibrated Segmentation & Copy-Number Calling**: Gap-aware euchromatic arm splitting, mBIC-calibrated `ruptures.Pelt` change-point detection, multi-scale dyadic BLUE segment Z-scores, and discrete integer copy-number Bayes factor calling ($`CN \in \lbrace 0, 1, 2, 3, 4+\rbrace`$) resolving focal and homozygous deletions ($`CN=0`$) down to $`0.1\times`$ sequencing coverage.
- **Prenatal cfDNA Screening & Segment Origin Classification**: Multi-modal fetal fraction estimation (`FFY` Poisson MSY MLE, 100 kb `FFA` logit-link ensemble, forward-calibrated $`R_X`$ `FFX`, maternal/fetal fragment-size deconvolution, reference-side 24-band Fisher read weighting, and 36-feature `FF_size`) fused via Student-$`t_4`$ IRLS (`active_ff`), paired with a 4D `erfc` ray-marginalized sex chromosome aneuploidy classifier (`XX`, `XY`, `XO`, `XXX`, `XXY`, `XYY`, `DISCORDANT_MIXED`), analytical limit-of-detection profiling, and a 5-state coupled depth + Dirichlet-Multinomial segment origin engine (`FETAL_CONSTITUTIONAL`, `PLACENTAL_MOSAIC`, `MATERNAL_UNINHERITED`, `MATERNAL_AND_FETAL_INHERITED`, `MATERNAL_MOSAIC`, `INDETERMINATE`).
- **Deliverables, Interactive Visualization & Quality Control**: Single-pass bgzipped and indexed bin, segment, and call BED tracks, optional VCFv4.2 structural variant outputs (`--vcf`, `--bins-vcf`), self-contained interactive Plotly HTML genome viewers (`_plot.html`) with M4 trace decimation and UCSC cytoband ideograms (auto-populated from bundled GRCh38 `cytoBand_hg38.gz` when canonical contig lengths match `hg38` or overridden via `--cytobands`), and structured JSON QC reports (`<prefix>_qc.json`) with `ccnv ref-qc` usability verdicts (`PASS`, `WARN`, `FAIL`).
- **Documentation, Packaging & CI**: Zensical documentation site covering pipeline architecture, CLI specification, interactive visualization guide ([docs/visualization.md](docs/visualization.md)), mathematical methodology, and AST-verified API reference ([docs/api.md](docs/api.md)) with Mermaid call-graph DAGs, alongside multi-platform Python `abi3` wheels (`linux/x86_64`, `linux/aarch64`, `macos/arm64`) and slim multi-arch GHCR Docker images.
