# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

> [!NOTE]
> `ccnv` is in active pre-1.0 alpha development (`0.1.0dev`). CLI interfaces, data models, and schemas may evolve before the initial stable release.

## [Unreleased]

### Added

- **Four-Stage CLI & Python Pipeline**: Organism-agnostic whole-genome sequencing (WGS) copy-number workflow across any coverage via `ccnv extract`, `ccnv reference`, `ccnv ref-qc`, and `ccnv predict` (plus programmatic `ccnv` entry points), supporting constitutional CNV profiling (`--mode germline`) and cell-free DNA non-invasive prenatal screening (`--mode prenatal`) on 0-based half-open `[start, end)` coordinates.
- **Compiled Rust Genomic I/O Engine (`ccnv._core`)**: PyO3 `abi3` Rust extension wrapping `noodles` and `bigtools` for multi-threaded indexed BAM/CRAM tile streaming (and index-free single-threaded streaming), single-pass FASTA GC and 200 bp GC quantile scanning, BigWig mappability and GC aggregation, and multi-threaded BGZF compression with `.tbi`/`.csi` indexing.
- **Versioned Arrow/Parquet Storage & Dynamic Rebinning**: Zstandard-compressed Apache Arrow/Parquet `.ccnv` schema (`2.0.0`) storing coordinate-free per-bin read counts and cfDNA fragmentomic channels (`paired_count`, `frag_len_sum`, `short_frag_count`, `endpoint_count`, `frag_gc_sum`, and 24-band `frag_bands`), sample-level fragment size histograms and 5' 4-mer end-motif spectra, branch-partitioned reference models, and automatic in-memory rebinning across compatible genome builds.
- **Within-Sample Reference Normalization & Cohort Modeling**: Cohort samplesheet (`-s/--samplesheet`) and cohort-free FASTA (`--fasta`) reference construction with automated 2D germline sex inference and outlier quarantine, 1 Mb super-block DESeq2 depth scaling, zero-inclusive Poisson GC/mappability/fragmentomic bias correction, Gavish-Donoho SVHT PCA denoising with robust `HuberRegressor` projection, off-contig `MiniBatchKMeans` Prototype Graph baselines, and Smyth Empirical Bayes biological overdispersion shrinkage.
- **Calibrated Segmentation & Copy-Number Calling**: Gap-aware euchromatic arm splitting, mBIC-calibrated `ruptures.Pelt` change-point detection, multi-scale dyadic BLUE segment Z-scores, and discrete integer copy-number Bayes factor calling ($`CN \in \lbrace 0, 1, 2, 3, 4+\rbrace`$) resolving focal and homozygous deletions ($`CN=0`$) down to $`0.1\times`$ sequencing coverage.
- **Prenatal cfDNA Screening & Segment Origin Classification**: Multi-modal fetal fraction estimation (`FFY` Poisson MSY MLE, 100 kb `FFA` logit-link ensemble with degenerate $`\lVert \mathbf{w}_{\text{olm}} \rVert_2`$ variance scaling, forward-calibrated $`R_X`$ `FFX`, maternal/fetal fragment-size deconvolution, reference-side 24-band Fisher read weighting, and 36-feature `FF_size`) fused via Student-$`t_4`$ IRLS (`active_ff`), paired with a 4D `erfc` ray-marginalized sex chromosome aneuploidy classifier (`XX`, `XY`, `XO`, `XXX`, `XXY`, `XYY`, `DISCORDANT_MIXED`), a 2-fetus twin pregnancy stoichiometry classifier (`FF`, `FM`, `MM`, `--twins`, with de novo `twin_probability` reported alongside `sca` in `<prefix>_qc.json` and embedded in `_plot.html` JSON alongside the displayed twin sex pair, per-sex fetal fractions, and SCA badge), analytical limit-of-detection profiling, and a 5-state coupled depth + Dirichlet-Multinomial segment origin engine (`FETAL_CONSTITUTIONAL`, `PLACENTAL_MOSAIC`, `MATERNAL_UNINHERITED`, `MATERNAL_AND_FETAL_INHERITED`, `MATERNAL_MOSAIC`, `INDETERMINATE`).
- **Deliverables, Interactive Visualization & Quality Control**: Single-pass bgzipped and indexed bin, segment, and call BED tracks, optional VCFv4.2 structural variant outputs (`--vcf`, `--bins-vcf`), self-contained interactive Plotly HTML genome viewers (`_plot.html`) with M4 trace decimation and UCSC cytoband ideograms (auto-populated from bundled GRCh38 `cytoBand_hg38.gz` when canonical contig lengths match `hg38` or overridden via `--cytobands`), and structured JSON QC reports (`<prefix>_qc.json`) with `ccnv ref-qc` usability verdicts (`PASS`, `WARN`, `FAIL`).
- **Documentation, Packaging & CI**: Zensical documentation site covering pipeline architecture, CLI specification, interactive visualization guide ([docs/visualization.md](docs/visualization.md)), mathematical methodology, and AST-verified API reference ([docs/api.md](docs/api.md)) with Mermaid call-graph DAGs, Pixi release and schema-version maintenance tasks (`bump-version` and `bump-schema`), alongside multi-platform Python `abi3` wheels (`linux/x86_64`, `linux/aarch64`, `macos/arm64`) and slim multi-arch GHCR Docker images.

### Changed

- **Privacy-Safe Parquet Metadata (No Paths or Sample IDs)**: Removed `ccnv.source_identity`, `ccnv.reference_identity`, and `ccnv.sample_identities` from `.ccnv` Parquet artifacts (`SampleMetadata`, `ReferenceMetadata`, and `ref-qc` JSON) so internal filesystem paths and clinical sample IDs are never persisted in sample sketches or distributable reference models; replaced `sample_identities` with an integer `sample_count` inside `ccnv.model` and derived prediction QC `sample` names from `--prefix`.

### Fixed

- **5-State Origin Mosaic Normalization & Sizing-Shift Alignment**: Replaced the unnormalized `+ math.log(jacobian)` term in `_integrate_mosaic_state` with proper uniform prior normalization (`- math.log(max(m_high - m_low, 1e-9))`), aligned 571-bin reference fetal and maternal length densities by `-sizing_shift_bp` in `annotate_prenatal_origin_and_lod` / `annotate_sample_prenatal_segments` prior to 24-band Dirichlet-Multinomial scoring, and capped twin-scaled analytical LoD estimates at `<= 1.0`.
- **Compound-Poisson Fisher Weighting Dispersion & MSY EM Final E-Step**: Updated `evaluate_band_weighted_counts`, `build_fisher_weighted_cohort`, and `shrink_kish_kappa` to compute exact compound-Poisson variance dispersion factors ($`\sum w_j^2 / \sum w_j`$) rather than clamped Kish factors, and recomputed `p_male` on the final E-step in `fit_msy_sex_mixture`.
- **Organism-Agnostic `chrY` Usability Metric in `ref-qc`**: Updated `compute_signal_contig_metrics` and `evaluate_male_verdict` to compute `usable_pct` over unmasked (`n_valid`) sex-signal contig bins rather than total bins (preventing false `FAIL` verdicts on human GRCh38/T2T references whose heterochromatic `Yq12` and ampliconic regions mask ~73% of `chrY`), while adding an explicit `unmasked_pct < 5%` (`CHRY_MIN_UNMASKED_PCT_FAIL`) failure guard against collapsed or heavily masked signal contigs.
